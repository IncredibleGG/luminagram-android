## The name and the logo

**"LuminaGram", the LuminaGram logo, and the LuminaGram application icons are
not licensed under the GPL.** Copyright licences and trademark rights are
separate things; a licence to copy code has never been a licence to use the
name it was published under. GPLv2 grants rights over the code alone; it never
granted rights to trade names, trademarks or service marks in the first place.

This is the same arrangement Mozilla, Signal and many other projects use, and
it exists for one reason: so that a build nobody here produced cannot present
itself to users as if we had.

### If you fork this project

You are welcome to. Please replace the branding before you distribute your
build:

- the application name shown to users, and the executable / package name
- the launcher, window and installer icons
- in-app branding strings and the About screen
- the update feed and download URLs, so your users receive *your* updates
- the bundle identifier and any application ID derived from ours

Once your build no longer identifies itself as LuminaGram, nothing in this file
restricts you.
